# ⚡ Sentinel OS Ecosystem (v5.0 / v8.0)

**Авторский комплекс системной автоматизации, безопасности и управления мульти-мониторным пространством для Windows 10 / 11 (x64).**  
🌐 **Официальный сайт и документация:** [https://vladosic15-cpu.github.io](https://vladosic15-cpu.github.io)

## 📦 Состав репозитория

| Файл | Назначение | Версия |
| :--- | :--- | :--- |
| **`sentinel_setup.bat`** | **Core Deployment & Launcher Deck** — автоустановщик Python 3.11 (с защитой от заглушки Microsoft Store), верификатор библиотек и интерактивный ANSI-лаунчер. | `v5.0` |
| **`file_sorter.pyw`** | **Sentinel OS Core** — автоматическая сортировка `Downloads` с буфером «Недавнее», быстрый поиск дубликатов **Smart MD5**, сигнатурный антивирусный аудит, телеметрия CPU/RAM и сброс GPU (`Win+Ctrl+Shift+B`). | `v5.0` |
| **`sentinel_dimmer.pyw`** | **Sentinel Focus Shade Matrix** — плавное (60 FPS) затемнение неактивных мониторов, слежение за курсором, индивидуальная блокировка экранов по ПКМ, тепловые фильтры для глаз и кастомные бинды (`Keyboard + Mouse4/Mouse5`). | `v8.0` |

---

## 🚀 Быстрый старт

1. Скачайте все 3 файла в одну папку (или используйте кнопку комплектной загрузки на [сайте](https://vladosic15-cpu.github.io)).
2. Запустите **`sentinel_setup.bat`**.
3. Нажмите **`[1]`** в меню лаунчера для одновременного фонового запуска обоих модулей или **`[4]`** для создания ярлыков на Рабочем столе.
