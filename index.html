# Sentinel OS Core v4.5 — Руководство

1. Что делает эта утилита?

Sentinel OS Core работает в фоне или полноэкранном кибер-интерфейсе. Приложение непрерывно мониторит системную папку Загрузок (C:\Users\...\Downloads), перекладывая только что скачанные файлы во временную буферную папку «Недавнее». Спустя заданное время (по умолчанию 1.5 часа) файлы сортируются по категориям (Аудио, Архивы, Видео, Minecraft Моды, Софт и др.) и раскладываются по расширениям.

2. Ключевые возможности

  • Защита от повреждений: не трогает незавершённые загрузки браузера (.crdownload, .part, .tmp).
  • Дедупликация MD5: находит идентичные файлы любого размера по хеш-сумме и очищает дубликаты.
  • Sentinel-AV: проверяет файл hosts, ключи реестра автозапуска Windows, активные процессы в RAM и сигнатуры скриптов на наличие вредоносных команд (PowerShell hidden, shadow delete и др.).
  • Аппаратная телеметрия: вывод характеристик ЦП, ядер, занятости ОЗУ и видеокарты.

3. Установка и первый запуск

# 1. Убедитесь, что установлен Python 3.10+ с галочкой "Add python.exe to PATH"

# 2. Необходимые библиотеки установятся автоматически при первом запуске (pystray, pillow, psutil)

# 3. Запуск:

python sentinel_os.py

4. Команды встроенного терминала

В нижней строке терминала поддерживаются команды: scan, sort, antivirus, clean, dups, specs, а также встроенные пасхалки.

# Focus Shade Matrix — Руководство

1. Назначение и суть

Focus Shade Matrix спроектирован для работы с конфигурациями из нескольких дисплеев. Он создаёт прозрачные системные оверлеи через WinAPI (WS_EX_TRANSPARENT | WS_EX_LAYERED), которые пропускают через себя все клики мыши, но затемняют экраны, на которых сейчас нет внимания пользователя.

2. Режимы работы

  • Следование за курсором (Strict Follow): Затемняются все мониторы, кроме того, на котором прямо сейчас находится курсор мыши. При переводе мыши на другой экран фокус плавно и мгновенно переключается.
  • Фиксированный основной монитор: Можно кликнуть по любому монитору на интерактивной карте, чтобы он оставался ярким, а все остальные — затемненными.

3. Управление биндами

По умолчанию быстрое включение и выключение затемнения назначено на клавишу F9. Чтобы изменить хоткей:

  1. Нажмите желтую кнопку «⌨ БИНД: ...» в окне программы.
  2. Зажмите любую комбинацию на клавиатуре (например, Ctrl + Shift + X) или боковые кнопки мыши (Mouse4 / Mouse5).
  3. Комбинация сохранится автоматически.

4. Запуск без консоли

Файл имеет расширение .pyw, поэтому при запуске стандартное черное окно терминала Windows не появляется. Программа тихо сворачивается в системный трей возле часов.
