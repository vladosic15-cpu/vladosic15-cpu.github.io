# Sentinel OS Core v4.5

Как работает буфер: Все новые файлы из браузера попадают в папку «Недавнее» на 90 минут. Если файл нужен прямо сейчас — он под рукой. Спустя 90 минут программа сама распределяет его по нужным каталогам.

Защита системы: Кнопка «🛡 Антивирус OS» сканирует ключи автозагрузки, активные процессы в RAM и исполняемые скрипты на наличие вредоносных команд.

Очистка места: Кнопка «🎯 Удалить дубли» сверяет MD5-суммы и удаляет полные копии файлов, освобождая память накопителя.

# Focus Shade Matrix

Следование за мышью: Программа отслеживает экран с курсором. Неактивные мониторы автоматически приглушаются полупрозрачным черным оверлеем.

Горячие клавиши: Стандартный бинд — клавиша F9. Чтобы изменить, нажмите желтую кнопку бинда и зажмите нужную комбинацию на клавиатуре или боковые кнопки мыши (Mouse4 / Mouse5).
