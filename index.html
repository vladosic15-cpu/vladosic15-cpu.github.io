⏳ Умный буфер «Недавнее»

Новые скачанные файлы не разлетаются по папкам сразу, чтобы вы их не теряли. Они помещаются в папку «Недавнее» на 90 минут (время настраивается от 0 до 3 часов). Только когда буфер истекает, файл уходит в свою категорию и подпапку по расширению.

🛡 Антивирусный аудит (AV)

Пятиступенчатая проверка системы: анализирует файл hosts на блокировку антивирусов, сканирует ветки автозапуска в реестре, проверяет оперативную память на процессы из папок Temp/AppData и ищет скрытые вредоносные паттерны в скриптах.

🎯 Дедупликатор MD5 & Железо

Побайтово вычисляет криптографический хеш MD5 каждого файла и удаляет 100% копии, даже если у них разные имена. Включает окно телеметрии ПК (модель ЦП, ядра, загрузка ОЗУ, диски и видеокарта) и быстрый сброс видеодрайвера.

1. Куда и как раскладываются файлы?

Программа автоматически игнорирует недокачанные файлы браузеров (.crdownload, .part, .tmp), чтобы не повредить загрузку. Готовые файлы распределяются в C:\Users\Имя\Downloads по структуре Категория / Расширение / Файл:

Аудио: mp3, wav, flac, ogg
Архивы: zip, rar, 7z, iso, torrent
Картинки: png, jpg, webp, psd, svg
Видео: mp4, mkv, avi, mov, webm
Софт: exe, msi, bat, py, apk
Документы: pdf, docx, xlsx, txt, pptx
Minecraft: .jar (моды в отдельную папку)
Разное: все остальные форматы
2. Кнопки управления в верхней панели
  • ⚡ Сортировать: принудительно запускает проверку папки Загрузок прямо сейчас, не дожидаясь таймера.
  • 🔨 Внутри папок: наводит порядок внутри уже созданных категорий (раскладывает файлы по подпапкам их расширений).
  • 🎯 Удалить дубли (MD5): сканирует всю папку Загрузок, сравнивает файлы по хешу и удаляет лишние дубликаты, показывая сколько мегабайт освобождено.
  • 🛡 Антивирус OS: запускает глубокое сканирование. Если находит подозрительный файл (например, двойное расширение .pdf.exe или скрытый символ разворота текста), предлагает изолировать его в папку Quarantine.
  • 🧹 Очистить Temp: безопасно вычищает системную папку временных файлов Windows (AppData\Local\Temp).
  • 🚀 Автозапуск [ВКЛ/ВЫКЛ]: одним кликом добавляет или удаляет программу из автозагрузки Windows в реестре.
3. Команды встроенного зеленого терминала (внизу окна)

В строку Sentinel:~$ можно вводить как внутренние команды программы, так и любые системные команды Windows (например, ipconfig или ping):

help — список всех доступных команд
scan — мгновенная проверка папки Загрузок
sort — глубокая сортировка внутри подпапок
antivirus — запуск сканера безопасности
dups — запуск поиска дубликатов по MD5
specs — открыть окно телеметрии железа
relax — открыть пасхалку «Зона Спокойствия»
matrix / operator / rats — секретные протоколы

🖱 Следование за курсором

В режиме Strict Follow программа отслеживает координаты мыши с частотой 25 раз в секунду. Как только вы переводите курсор на соседний монитор — он мгновенно становится ярким, а предыдущий плавно затемняется.

👻 Прозрачность для кликов

Оверлеи создаются через низкоуровневые флаги WinAPI (WS_EX_TRANSPARENT и WS_EX_LAYERED). Затемнение вообще не мешает нажимать на окна под ним и не сворачивает полноэкранные игры.

⌨ Любые бинды (Мышь + Клава)

Включать и выключать затемнение можно из любой игры или программы. Поддерживаются как одиночные клавиши (по умолчанию F9), так и связки вроде Ctrl + Shift + X или боковые кнопки мыши Mouse4 / Mouse5.

1. Два режима работы: какой выбрать?
  • Режим №1 — «Следовать за мышью» (галочка включена по умолчанию): Идеально для повседневной работы на 2–3 экранах. Светлым остается только тот монитор, на котором сейчас находится ваш курсор. Остальные мониторы приглушены и не бьют по глазам в темноте.
  • Режим №2 — «Фиксированный основной монитор» (галочка снята): Идеально для запуска игры или просмотра фильма на одном экране. Вы просто кликаете левой кнопкой мыши по нужному монитору на интерактивной карте в программе — он назначается [ ОСНОВНЫМ ] и всегда остается ярким, даже если увести мышь на соседний экран.
2. Как поменять горячую клавишу и настроить ползунок?
  1. Для включения или отключения затемнения нажмите синюю кнопку «⚡ Включить Фокус» или клавишу F9.
  2. Чтобы сменить клавишу: нажмите на желтую кнопку «⌨ БИНД: F9» — она загорится голубым ([ Зажмите бинд... ]). Зажмите любую клавишу, комбинацию клавиш или боковую кнопку мыши и отпустите. Бинд сразу сохранится.
  3. Ползунок «ЗАТЕМНЕНИЕ» регулирует плотность черного фона от 20% (легкая тонировка) до 100% (полное отключение подсветки пикселей, как на OLED).
  4. Кнопка «⟳ Обновить сетку» пересканирует дисплеи, если вы подключили новый монитор или телевизор по HDMI/DisplayPort.

Частые вопросы по установке и запуску

Почему у файлов расширение .pyw, а не .exe?

Расширение .pyw — это официальный формат оконных приложений Python для Windows. В отличие от скомпилированных .exe файлов, на которые часто ложно срабатывает Защитник Windows (SmartScreen), исходный код .pyw полностью открыт, прозрачен для проверки и запускается напрямую через pythonw.exe без черного окна консоли.

Что делать, если файл открывается в Блокноте?

Значит, на компьютере еще не установлен Python или не привязаны ассоциации файлов. Скачайте сверху sentinel_setup.bat и запустите его — он сам скачает Python и настроит систему. Либо кликните правой кнопкой по файлу → «Открыть с помощью» → выберите Python.
