# Sentinel OS Core v4.5 — Руководство

1. Назначение

Sentinel OS Core держит в порядке директорию Загрузок (Downloads). Новые файлы попадают в буферную папку «Недавнее» на 90 минут, после чего автоматически раскладываются по категориям и типам расширений.

2. Возможности

  • Удаление дубликатов: вычисляет точный MD5-хеш и стирает копии.
  • Sentinel-AV: сканирует реестр Run, память и подозрительные скрипты на трояны/майнеры.
  • Телеметрия железа: мониторинг ЦП, ОЗУ, дисков и видеоадаптера.

3. Запуск

python file_sorter.pyw

Зависимости (psutil, pillow, pystray) программа скачает сама при первом старте.

# Focus Shade Matrix — Руководство

1. Назначение

Многомониторный оверлей для систем с 2-3 и более экранами. Затемняет неактивные мониторы через WinAPI-слои без блокировки кликов.

2. Управление

  • Следование за курсором: подсвечен только тот экран, где находится мышь.
  • Горячая клавиша: по умолчанию F9. Можно переназначить на боковые кнопки мыши (Mouse4 / Mouse5) прямо в интерфейсе.

3. Запуск

pythonw sentinel_dimmer.pyw

Запускается в фоне без окна консоли и прячется в системный трей.
